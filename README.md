## О проекте
KingPromotion создается как новый инструмент дкоторый работает на базе [**Soc-Rocket**](https://soc-rocket.ru/).

## Основная задача проекта
Сделать продвижение в соцсетях быстрее дешевле и качественнее.

Лично: Создать свой первый проект в портфолио

## Используемые технологии

### Frontend

- React — создание пользовательского интерфейса.
- Vite — запуск и сборка frontend-приложения.
- JavaScript — основная логика frontend.
- CSS — стилизация и адаптивная верстка.
- React Router — маршрутизация между страницами.
- Fetch API — запросы к backend.

### Backend

- Python — язык backend-разработки.
- FastAPI — создание API и серверных маршрутов.
- Uvicorn — запуск FastAPI-приложения.
- Pydantic — проверка и валидация данных.
- SQLAlchemy — подключение и работа с PostgreSQL.
- PyJWT — создание и проверка JWT-токенов.
- python-dotenv — загрузка переменных из `.env`.

### База данных

- PostgreSQL — общее хранилище King Promotion.
- SQL — запросы к базе данных.
- Схема `migration_temp` — основная схема существующей базы KingPromotion.

### Авторизация

- JWT — авторизация пользователей.
- Telegram Bot API — вход

## Основные возможности проекта

- Регистрация с помощью логина и пароля
- Авторизация с помощью Telegram bot и VK ID
- Сохранение сессии
- Получение цен с api SocRocket и дальнейшее отображение в панельке быстрого заказ
- Создание каталога По данным цен из SocRocket
- Валидация пароля при регистрации
- Оплата по YooKassa

## Как система работаем в целом
```
    Пользователь
            ↓
    Frontend (React)
            ↓
    Backend API (FastAPI)
         ├── PostgreSQL
         ├── Soc-Rocket API
         ├── YooKassa
         ├── Telegram Bot API
         └── VK ID API
```

- **Frontend** - отвечает за интерфейс и отправляет запросы на backend
- **Backend** - обрабатывает запросы frontend и получает данные с нужных api
- **PostgreeSQL** - Основное постоянное хранилище данных KingPromotion.
- **Soc-Rocket API** - это стороний сервис предоставляющий возможность образатсья к их системе продвижения различных социальных сетей с помощью api. Предоставление данных о расценках, и исполнение заказа осуществяются этим сервисом. Kingpromotion выступает в роли посредника с оформлением заказа и последующей переадресацией его на [**Soc-Rocket**](https://soc-rocket.ru/).
- **YooKassa** - используется для оплаты услуг. Всё также по api.
- **Telegram Bot API** - создан для авторизации на сайте. Несет функцию посредника между сессией в браузере телеграм аккаунтом и PostgreeSQL. Он нужен для вохмоджности апвтризации по телеграм аккаунту через бота.
- **VKID API** - Осуществляет вход через VK аккаунт. Служит альтерноттивой Telegram, не требует ботов, авторизация в вк автоматизированна я на стороне сервиса, в Kingpromotion приходит лишь токен об окончании автороизации с данными пользователя.
