# Задачи
 - Поднять базу данных локально.
 - Изучить все таблицы и связи между ними.
 - Создать модели SQLAlchemy для каждой таблицы.
 - Написать репозитории (repositories) — функции, которые получают, создают, обновляют и удаляют данные.
 - Написать сервисы (services) — вся бизнес-логика проекта.
 - Создать FastAPI и добавить роуты (routes), которые вызывают сервисы.
 - Подключить React к API.
