# KING PROMOTION UPDATES v1.0.0

## Обновление 23.08.2026
### backend
- Добавлена авторизация через Telegram-бота.
- Telegram-бот переписан на `aiogram3`.
- Для бота добавлен отдельный конфиг `backend/bots/config.py`.
- Бот больше не импортирует `backend/core/config.py` и не зависит от `DATABASE_URL`.
- При запуске бот выводит в консоль сообщение о старте.
- Ошибка подключения к Telegram API теперь выводится понятным сообщением.
- Добавлены временные Telegram-сессии в таблице `telegram_auth_sessions`.
- Telegram-token хранится в базе как `sha256`-хеш.
- Добавлена таблица `user_social_accounts` для привязки соцсетей к пользователю.
- Telegram ID теперь можно привязать к аккаунту пользователя.
- Один Telegram не может быть привязан к нескольким аккаунтам.
- Один аккаунт не может иметь несколько Telegram-привязок одного провайдера.
- Добавлен сценарий входа через Telegram для нового пользователя.
- Если Telegram уже привязан, backend сразу выдаёт JWT.
- Если Telegram новый, backend требует завершить создание или связку аккаунта.
- Добавлены endpoints:
  - `POST /auth/telegram/session`
  - `POST /auth/telegram/guest/session`
  - `GET /auth/telegram/guest/status`
  - `POST /auth/telegram/start`
  - `POST /auth/telegram/complete-register`
  - `POST /auth/telegram/link-existing`
  - `GET /auth/social/accounts`
- Auth-роуты разделены на отдельные файлы в `backend/auth/routers`.
- `backend/auth/router.py` теперь является сборщиком auth, social и telegram роутеров.
- `backend/core/config.py` очищен от настроек, которые нужны только Telegram-боту.
- Настройки `TELEGRAM_BOT_TOKEN` и `BACKEND_PUBLIC_URL` перенесены в конфиг бота.

### frontend
- Добавлены иконки Telegram и VK под кнопками входа и регистрации.
- Кнопка Telegram теперь создаёт Telegram-сессию через backend.
- Telegram-бот открывается в новой вкладке, сайт остаётся открытым.
- Сайт проверяет статус Telegram-сессии после подтверждения в боте.
- Если Telegram уже привязан, пользователь автоматически авторизуется и попадает в `/main`.
- Если Telegram новый, пользователь переходит на отдельную страницу `/telegram-auth`.
- Добавлена страница `/telegram-auth` для завершения Telegram-входа.
- На `/telegram-auth` можно создать новый аккаунт или связать Telegram с существующим аккаунтом.
- Telegram-token больше не хранится в `localStorage`.
- При обновлении страницы старая плашка завершения Telegram-входа больше не появляется.
- Исправлено восстановление авторизации после обновления страницы.
- Если JWT валиден, пользователь остаётся в аккаунте.
- Добавлена кнопка `Выйти` в хедере личного кабинета.
- При выходе токен удаляется, а пользователь возвращается на главную страницу.
- Из кнопок `Войти` и `Создать аккаунт` убраны стрелки.
- Строка `Уже есть аккаунт?` / `Нет аккаунта?` поднята выше.
- Иконки Telegram и VK выровнены под кнопками входа и регистрации.

### prices
- Backend получает цены услуг через KingPromotion API.
- API-ключ KingPromotion читается из `.env`.
- Добавлена наценка через `KINGPROMOTION_MARKUP_PERCENT`.
- Backend отдаёт основную цену и сравнительную цену с наценкой 75%.
- Frontend использует цены из `/price` при расчёте заказа.
- Платформы из `other` нормализуются в обычные платформы на backend.
- Исправлен расчёт скидки за объём.
- Скидка за объём применяется от 1000 единиц.
- Если количество меньше 1000, скидка отображается как `0%`.

### checks
- Проверена сборка frontend через `npm run build`.
- Проверена компиляция backend-файлов через `py_compile`.
- Проверен импорт `backend.main`.
- Проверен запуск Telegram-бота до polling.

```
  ├── __init__.py

  │

  │   ├── __init__.py
  │   ├── router.py ---------> Маршрутизатор для аутентификации
  │   ├── schemas.py --------> Схемы для получения данных
  │   ├── service.py --------> Сервис для аутентификации пользователей
  │   ├── repository.py -----> Функции для взаимодействия с базой данных
  │   ├── security.py -------> Cодержит функции хеширования паролей, создания и
  │   │                        декодирования JWT-токенов
  │   └── dependencies.py ---> зависимости для аутентификации и авторизации

```
