- Обновлен второй вариант лендинга: отдельный hero, регистрация справа, поддерживаемые площадки и старый стиль левой части
- Добавлена заготовка третьего варианта лендинга для дальнейших экспериментов

## Обновление 3.08.2026
- Разработан сервер, подключенный к актуальной базе данных на PostgreSQL;
- Создан обработчик авторизации
- Создан обработчик сохранения сессий
- Разработана архитектура, в которой всё распределено на модули
```
backend/
  ├── __init__.py
  ├── main.py ----> Основной файл входа в Fast Api
  ├── .env
  │
  ├── core/ -----------------> Модуль взаимоджействия с БД
  │   ├── __init__.py
  │   ├── config.py ---------> Получение данных из .env
  │   └── database.py -------> Настройки подключения к базе данных
  │
  ├── auth/ -----------------> Модуль обработчика авторизации
  │   ├── __init__.py
  │   ├── router.py ---------> Маршрутизатор для аутентификации
  │   ├── schemas.py --------> Схемы для получения данных
  │   ├── service.py --------> Сервис для аутентификации пользователей
  │   ├── repository.py -----> Функции для взаимодействия с базой данных
  │   ├── security.py -------> Cодержит функции хеширования паролей, создания и
  │   │                        декодирования JWT-токенов
  │   └── dependencies.py ---> зависимости для аутентификации и авторизации

```
