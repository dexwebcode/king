# Документация Hero

Модуль `Hero` отвечает за первый экран лендинга KING PROMOTION: заголовок, описание, кнопки действий, список преимуществ, поддерживаемые площадки и форму регистрации/входа.

```
Hero/
  ├── HERO.md --------------------------> Документация структуры модуля Hero
  ├── Hero.jsx -------------------------> Основной компонент первого экрана лендинга
  ├── HeroRegisterForm.jsx -------------> Обертка над формами входа и регистрации
  │
  └── css/ -----------------------------> Стили компонента Hero, разделенные по зонам
      ├── Hero.css ---------------------> Точка для общих стилей Hero; стили импортируются напрямую из папок ниже
      ├── Visual.css -------------------> Стили визуальной правой части, карточки регистрации, иконок и анимаций
      │
      ├── actions/ ---------------------> Стили блока кнопок действий
      │   └── HeroActions.css ----------> Кнопки "Быстрый заказ" и "Каталог"
      │
      ├── benefits/ --------------------> Стили блока преимуществ
      │   └── HeroBenefits.css ---------> Карточки преимуществ: цена, поддержка, безопасность
      │
      ├── content/ ---------------------> Стили текстовой части Hero
      │   ├── HeroCopy.css -------------> Общая компоновка текста, eyebrow и анимация появления
      │   ├── HeroSubtitle.css ---------> Подзаголовок и его выравнивание
      │   └── HeroTitle.css ------------> Главный заголовок и варианты отображения слева
      │
      ├── layout/ ----------------------> Стили основной сетки и позиционирования
      │   └── HeroLayout.css -----------> Размеры, CSS-переменные, отступы и расположение контента
      │
      ├── order-card/ ------------------> Стили карточки заказа внутри Hero
      │   └── HeroOrderCard.css --------> Шаги заказа, выбор платформы, услуг и футер карточки
      │
      ├── platforms/ -------------------> Стили списка поддерживаемых площадок
      │   └── HeroPlatforms.css --------> Иконки Instagram, YouTube, TikTok, Telegram, VK и X
      │
      └── responsive/ ------------------> Адаптивные стили Hero
          └── HeroResponsive.css -------> Правила для планшетов, мобильных и маленьких экранов
```

## Компоненты

### `Hero.jsx`

Основной React-компонент первого экрана.

- Импортирует стили из папки `css/`.
- Подключает `HeroRegisterForm`.
- Импортирует SVG-иконки социальных площадок из `frontend/src/assets/social_icons/`.
- Хранит массив `supportedPlatforms` для вывода списка поддерживаемых площадок.
- Хранит массив `heroBenefits` для вывода преимуществ.
- Принимает проп `isOrderGuideActive`, который добавляет класс `hero--order-guide`.
- Рендерит:
  - текстовый блок `hero-copy`;
  - eyebrow "Продвижение в социальных сетях";
  - главный заголовок;
  - подзаголовок;
  - кнопки перехода к `#quick-order` и `#prices`;
  - блок преимуществ;
  - список поддерживаемых площадок;
  - визуальную колонку с формой регистрации.

### `HeroRegisterForm.jsx`

Компонент формы в правой части Hero.

- Использует `useState` для режима формы и полей ввода.
- Подключает `LoginForm` и `RegisterForm` из модуля `Auth`.
- Подключает общие стили авторизации `Auth.css`.
- Принимает проп `initialMode`, по умолчанию `"register"`.
- Переключает отображение между:
  - `LoginForm` для входа;
  - `RegisterForm` для регистрации.
- Хранит значения `email`, `password`, `repeatPassword`, `emailHint`, `passwordHint`.
- Передает сеттеры состояния во вложенные формы.

## CSS-структура

### `layout/HeroLayout.css`

Задает базовую компоновку секции:

- класс `.hero`;
- CSS-переменные ширины, отступов и позиции формы;
- минимальную высоту первого экрана;
- позиционирование `.hero-content`;
- левый вариант отображения через `.hero--left`.

### `content/HeroCopy.css`

Отвечает за текстовый блок:

- `.hero-copy`;
- `.eyebrow`;
- анимацию `heroRevealUp`;
- задержки появления заголовка, подзаголовка, кнопок и карточки заказа;
- отключение анимаций при `prefers-reduced-motion: reduce`.

### `content/HeroTitle.css`

Описывает главный заголовок:

- размеры и line-height для `.hero h1`;
- отображение заголовка в несколько строк;
- левый вариант `.hero--left .hero-main-title`.

### `content/HeroSubtitle.css`

Описывает подзаголовок:

- максимальную ширину;
- цвет через `var(--muted)`;
- размер шрифта и line-height;
- левое выравнивание для `.hero--left`.

### `actions/HeroActions.css`

Описывает блок кнопок:

- раскладку `.hero-actions`;
- размеры кнопок;
- золотую основную кнопку `.hero-action-primary`;
- левое выравнивание кнопок в варианте `.hero--left`.

### `benefits/HeroBenefits.css`

Описывает блок преимуществ:

- сетку `.hero-benefits`;
- карточку `.hero-benefit`;
- иконку `.hero-benefit-icon`;
- компактный горизонтальный вариант для `.hero--left`.

### `platforms/HeroPlatforms.css`

Описывает список поддерживаемых площадок:

- контейнер `.hero-platforms`;
- вариант `.hero-platforms--left`;
- список `.hero-platform-list`;
- элемент площадки `.hero-platform-item`;
- размеры SVG-иконок.

### `order-card/HeroOrderCard.css`

Описывает карточку заказа, если она используется внутри Hero:

- позиционирование `.hero-order-card`;
- заголовок и футер карточки;
- линию шагов `.steps-line`;
- шаги `.step`;
- блоки полей `.field-block`;
- компактную сетку платформ `.platform-grid.compact`;
- кнопки услуг `.service-pills`.

### `Visual.css`

Описывает правую визуальную часть:

- `.hero-visual`;
- `.hero-form-column`;
- `.hero-register-card`;
- шапку формы `.hero-register-header`;
- размеры полей внутри карточки регистрации;
- декоративные и социальные иконки;
- hover-состояния иконок;
- анимацию `heroVisualItemReveal`;
- адаптивность визуальной части для планшета и мобильных экранов.

### `responsive/HeroResponsive.css`

Содержит общие адаптивные правила:

- до `1050px` меняет размеры заголовка и позицию карточки заказа;
- до `800px` переводит Hero в одноколоночную компоновку;
- до `550px` перестраивает кнопки, сетку платформ, услуги и шаги.
