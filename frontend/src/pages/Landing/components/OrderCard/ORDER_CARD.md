# Документация OrderCard

Модуль `OrderCard` отвечает за интерактивную панель создания заказа на лендинге: выбор площадки, услуги, количества, скорости и итоговый блок "Ваш заказ".

  ├── OrderCard.jsx --------------------> Основной интерактивный компонент создания заказа
  │
  └── css/ -----------------------------> Стили OrderCard, разделенные по зонам
      ├── OrderCard.css ----------------> Точка входа; импортирует все CSS-файлы ниже

      │
      ├── header/ ----------------------> Верхняя часть панели
      │   └── OrderCardHeader.css ------> Заголовок, описание, badge "Поддержка 24/7", divider
      │
      ├── settings/ --------------------> Левая часть формы заказа

## Компонент

### `OrderCard.jsx`

Основной React-компонент панели создания заказа.

- Импортирует `OrderCard.css`, который подключает все стили модуля.
- Импортирует SVG-иконки площадок из `frontend/src/assets/social_icons/`.
- Хранит массив `platforms` для выбора социальной сети.
- Хранит массив `speeds` для выбора скорости выполнения.
- Принимает проп `isGuidePinned`, который фиксирует раскрытое/выпрямленное состояние панели.
- Принимает проп `onGuidePanelHover`, который вызывается при активации hover-состояния.
- Использует локальные состояния:
  - `platform` - выбранная площадка;
  - `service` - выбранная услуга;
  - `quantity` - количество;
  - `speed` - скорость;
  - `isHoverReady` - активировано ли hover-состояние после задержки.
- Использует `hoverDelayTimer`, чтобы включать hover-состояние с задержкой `200ms`.
- При размонтировании очищает таймер через `useEffect`.

## Структура JSX

Компонент рендерит:

- `.order-card-scene` - внешний контейнер с перспективой и hover-состоянием;
- три `.order-card-depth` слоя для 3D-толщины панели;
- `.order-card` - основную цельную панель;
- `.order-card-header` - заголовок "Новый заказ" и badge поддержки;
- `.order-card-content` - сетку из двух внутренних колонок;
- `.order-settings` - левая колонка с настройками заказа;
- `.order-summary` - правая колонка с итогами заказа.

`order-summary` находится внутри `.order-card`, поэтому не выезжает отдельной панелью. Итоги заказа всегда являются частью одной общей панели.

На лендинге секция `#quick-order` размещает карточку в правой части экрана. Ширина `.order-card-scene` ограничена `900px`, а дополнительный правый отступ задается в `Landing.css` через `margin-right: clamp(20px, 2.5vw, 45px)`.

## Поведение

### Выбор площадки

Площадки берутся из массива `platforms`.

Текущий порядок:

1. Instagram
2. YouTube
3. TikTok
4. Telegram
5. VK
6. Twitter (X)

При клике обновляется `platform`, активная кнопка получает класс `.active`, а блок "Ваш заказ" показывает выбранную площадку.

Кнопка площадки внутри выстроена сеткой:

- левая колонка - иконка;
- центральная колонка - название;
- правая колонка - галочка выбора.

Для неактивных кнопок правая колонка резервируется псевдоэлементом, чтобы карточки не меняли внутреннее выравнивание при выборе.

### Выбор услуги

Услуга хранится в `service` и выбирается через `<select>`.

Доступные варианты:

- Подписчики
- Лайки
- Просмотры
- Комментарии

### Количество

Количество хранится в `quantity`.

- кнопка `−` уменьшает значение на `100`;
- минимальное значение ограничено `100`;
- кнопка `+` увеличивает значение на `100`;
- отображение форматируется через `toLocaleString("ru-RU")`.

### Скорость

Скорости берутся из массива `speeds`.

Доступные варианты:

- Стандарт - `1-2 дня`;
- Ускоренная - `До 12 часов`;
- Молниеносная - `До 2 часов`.

Выбранная скорость получает класс `.active` и отображается в summary.

## 3D и hover

В обычном состоянии `.order-card` слегка повернута:

- `rotateX(2deg)`;
- `rotateY(-8deg)`;
- `rotateZ(-1deg)`;
- применяется очень легкий `blur(0.18px)` и мягкое затемнение.

При наведении, фокусе или `isGuidePinned`:

- карточка выпрямляется;
- `blur` убирается;
- яркость возвращается к нормальной;
- depth-слои тоже выпрямляются;
- текст становится визуально четче.

Когда мышь уходит, `isHoverReady` сбрасывается и панель возвращается в повернутое состояние.

## CSS-структура

### `css/OrderCard.css`

Точка входа для стилей:

- импортирует CSS-файлы в порядке от базового каркаса к адаптиву;
- подключается только один раз в `OrderCard.jsx`.

### `css/layout/OrderCardFrame.css`

Содержит:

- `.order-card-scene`;
- `.order-card`;
- hover/focus/guide-pinned transform-состояния;
- ширину карточки `min(900px, calc(100vw - 48px))`;
- `.order-card-depth` и его три слоя;
- общие `.platform-icon` и `.platform-icon-image`.

### `css/header/OrderCardHeader.css`

Содержит:

- `.order-card-header`;
- `.order-card-title-wrapper`;
- стили заголовка и описания;
- `.support-badge`;
- `.support-dot`;
- `.order-card-divider`.

### `css/settings/OrderCardSettings.css`

Содержит левую часть панели:

- `.order-card-content`;
- `.order-settings`;
- `.order-section`;
- `.platform-grid`;
- `.platform-button`;
- `.selected-check`;

- `.service-select-wrapper`;
- `.service-select`;
- `.quantity-row`;
- `.quantity-control`;
- `.discount-badge`;

### `css/summary/OrderCardSummary.css`

Содержит правую часть панели:

- псевдоэлементы liquid-glass блика;
- `.summary-table`;
- `.summary-row`;
- `.summary-platform`;
- `.summary-price`;
- `.price-line`;
- `.saving-badge`;
- `.trust-grid`;
- `.trust-card`;
- `.trust-icon`;
- `.clients-card` и связанные классы, если блок клиентов используется.

### `css/actions/OrderCardPayment.css`

Содержит:

- `.payment-button`;
- hover/active состояния кнопки оплаты;
- `.payment-arrow`;
- `.order-terms`;
- ссылку правил внутри `.order-terms`.

### `css/effects/OrderCardEffects.css`

Содержит декоративные псевдоэлементы основной панели:

- `.order-card::before`;
- `.order-card::after`.

### `css/responsive/OrderCardResponsive.css`

Содержит адаптив:

- до `900px` панель занимает всю ширину, а две колонки складываются в одну;
- до `600px` уменьшаются отступы, радиусы, заголовок и сетки;
- на мобильных скрывается `.support-badge`;
- площадки и скорости перестраиваются в более узкую сетку.

## Важные замечания

- `order-summary` должен оставаться внутри `.order-card-content`, чтобы не возвращалось поведение выезжающей отдельной панели.
- `OrderCard.css` должен оставаться единственной точкой импорта CSS в `OrderCard.jsx`.
- При изменении 3D-поворота нужно проверять оба состояния: обычное и hover/focus.
- При изменении размера или позиции карточки нужно проверять `Landing.css`, потому что правая позиция секции задается там.
- При изменении snap-scroll нужно учитывать, что `Landing.jsx` центрирует именно `.order-card-scene`.
- При изменении структуры summary нужно проверять мобильную версию, потому что после `900px` колонки становятся одним столбцом.
